# Milestones

## Milestone 0: Modelización inicial del dominio
En este hito se va a desarrollar el modelo inicial que corresponde a la HU001 utilizando DDD como metodología, partiendo de los conceptos y las relaciones que aparecen en esta historia de usuario.
Este hito lo consideraremos válido cuando se pueda representar en código los datos de la historia de usuario HU001 y las relaciones entre los elementos que intervienen en ella, pudiendo utilizarse para implementar la lógica de negocio .

## Milestone 1: Implementación lógica de negocio 
En este hito se incorporamos la lógica de negocio para resolver el problema que plantee en la HU001 a partir del modelo del anterior hito.
El hito se considerará válido cuando con las pruebas podamos comprobar quecon los datos de la HU001, se obtiene el resultado que esperábamos y que los problemas que se describen en las historias de usuario se resuelven correctamente.
